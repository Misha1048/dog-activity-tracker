#  Умная камера-няня: Трекер активности Лилы (Dog Activity Tracker)

**Дипломный проект:** Система распознавания и отслеживания активности домашней собаки с использованием алгоритмов машинного обучения и компьютерного зрения.

## О проекте
Данный проект представляет собой MVP системы видеонаблюдения для домашних питомцев. Алгоритм в реальном времени анализирует видеопоток, распознает позу собаки (французский бульдог) и фиксирует изменения в её активности («СИДИТ», «СТОИТ», «ЛЕЖИТ», «ЧЕШЕТСЯ»). Интерфейс реализован в виде интерактивного дашборда на фреймворке Streamlit.

### Ключевые особенности
* **Кастомная модель:** Использование легковесной архитектуры YOLOv8-Pose, дообученной специально под детекцию ключевых точек французского бульдога.
* **Распределенная архитектура:** Поддержка захвата RTSP-потока по локальной сети с IP-камер (TAPO), что позволяет вынести вычисления на локальный сервер/ПК.
* **Аппаратная фильтрация (False Positives):** Внедрен каскад геометрических фильтров (анализ пропорций, массы и положения силуэта в кадре), который эффективно отсекает людей в кадре и предотвращает ложные срабатывания.
* **Асинхронное логгирование:** Автоматическая генерация журнала событий с таймкодами при смене статуса активности.

## Инструкция по установке и запуску

Для корректной работы системы потребуется установленный дистрибутив Anaconda или Miniconda.

### 1. Подготовка окружения
Откройте терминал (Anaconda Prompt) и выполните следующие CLI-команды для создания виртуальной среды и установки зависимостей:

```bash
# Создание новой среды с Python 3.9
conda create -n diploma_env python=3.9 -y

# Активация среды
conda activate diploma_env

# Установка необходимых библиотек
pip install streamlit opencv-python pandas ultralytics
```

### 2. Загрузка весов модели
1. Создайте в папке с проектом директорию `runs/pose/lila_pose_model/weights/`
2. Поместите скачанный файл `best.pt` в эту папку.

### 3. Запуск веб-интерфейса
Убедитесь, что вы находитесь в корневой папке проекта и среда `diploma_env` активна. Запустите дашборд командой:

```bash
streamlit run app.py
```

После этого локальный сервер запустится, и интерфейс автоматически откроется в вашем браузере по адресу `http://localhost:8501`.

## Структура проекта
* `app.py` — главный исполняемый скрипт. Содержит логику веб-интерфейса, подключение к камере (через OpenCV), инференс YOLO-модели, блок фильтрации ложных срабатываний и математику расчета статусов активности.
* `requirements.txt` — список зависимостей проекта.
